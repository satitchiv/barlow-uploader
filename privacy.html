Privacy Policy

Last updated: 25 October 2026

Barlow Uploader is a private tool used only by the owner of the Barlow & Coby YouTube channel.

What it accesses

With the owner's permission, it uses the YouTube Data API to upload the channel's own videos and set their title, description, made-for-kids setting and release time.

By using this tool you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

What it stores

A login token is stored only on the owner's own computer. No personal data from any other person is collected, shared or sold. Revoking access makes the stored token useless; deleting the token file removes all stored data. This site uses no cookies.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
